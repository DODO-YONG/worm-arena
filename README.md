# 꿈틀 아레나 🐛

## ▶️ 바로 하기

**[👉 여기를 눌러 바로 플레이 (혼자 하기)](https://htmlpreview.github.io/?https://github.com/DODO-YONG/worm-arena/blob/main/public/solo.html)**

설치 없이 PC·휴대폰 브라우저에서 바로 실행됩니다.
(외부 미리보기 서비스로 열리기 때문에 처음 열 때 몇 초 걸릴 수 있습니다.)

브라우저에서 하는 지렁이 게임입니다. 먹이를 먹고 길어지고, 다른 지렁이의 앞을 가로막아 이기세요.
혼자 하기와 같은 네트워크(같은 와이파이)에서 함께 하기를 지원합니다.

## 조작법

- 🖱️ 마우스 방향으로 이동 · 클릭 또는 **스페이스** = 부스트 (빨라지는 대신 조금씩 짧아짐)
- 📱 화면을 터치해 방향 조절 · 왼쪽 아래 버튼 = 부스트
- 머리가 다른 지렁이 몸이나 맵 경계에 닿으면 끝납니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `public/solo.html` | 혼자 하기. 파일만 열면 바로 실행됩니다 (설치 불필요) |
| `public/index.html` | 함께 하기 화면. `server.py`가 켜져 있어야 동작합니다 |
| `server.py` | 함께 하기용 게임 서버 (파이썬 3.10 이상, 표준 라이브러리만 사용) |
| `start-server.bat` | Windows에서 더블클릭으로 서버 실행 |

## 혼자 하기

`public/solo.html`을 브라우저로 열면 됩니다.

## 함께 하기 (같은 네트워크)

1. 파이썬 3.10 이상을 설치합니다.
2. 서버를 실행합니다.
   - Windows: `start-server.bat` 더블클릭
   - 그 외: `python server.py` (포트 변경: `python server.py 9000`)
3. 서버 창에 표시된 주소로 접속합니다.
   ```
    이 컴퓨터     : http://localhost:8080
    같은 네트워크 : http://192.168.x.x:8080   ← 친구에게 보낼 주소
   ```
4. 끝낼 때는 서버 창에서 `Ctrl + C`를 누르거나 창을 닫습니다.

### 친구가 접속이 안 될 때 (Windows)

- 서버를 처음 켤 때 **"Windows 보안 경고"** 창이 뜨면 **액세스 허용**을 누르세요.
- 네트워크 프로필이 **공용**이면 다른 기기의 접속이 막힐 수 있습니다.
  집이나 사무실처럼 믿을 수 있는 네트워크라면 설정 → 네트워크 및 인터넷에서 프로필을 **개인**으로 바꾸세요.
- 친구 기기와 서버 PC가 같은 공유기/와이파이에 연결되어 있어야 합니다 (게스트 와이파이는 기기끼리 막혀 있는 경우가 많음).

## GitHub Pages로 올릴 경우

GitHub Pages는 정적 파일만 제공하므로 **혼자 하기(`solo.html`)만 동작**합니다.
함께 하기는 `server.py`를 실행할 컴퓨터나 서버가 필요합니다.

## 동작 구조

- 서버가 모든 게임 계산(이동·먹이·충돌·컴퓨터 지렁이)을 초당 30번 하고, 각 플레이어 화면 주변 상태만 초당 15번 보냅니다.
- 브라우저는 마우스 방향과 부스트 입력만 보내고, 받은 상태를 보간해서 부드럽게 그립니다.
